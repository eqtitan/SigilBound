# High-detail hero parts (phase F, step 56)

Quaternius **Universal Base Characters** and **Modular Character Outfits – Fantasy** (Source editions),
CC0 1.0: each folder's `License_Source.txt`, verbatim. Original pages: https://quaternius.itch.io/universal-base-characters
and https://quaternius.itch.io/modular-character-outfits-fantasy.

Taken from a public GitHub repository that redistributes the CC0 Source-edition glTF exports with their licence files
and a SHA256SUMS list (github.com/slopwarefactory/terra, `art/characters/quaternius/`; its README is kept here as
`SOURCE_README.md`). Every file was checked against that SHA256SUMS on download (all matched).

**Changed here:** the textures only, scaled down for phones (BaseColor and Normal 4096 -> 1024, ORM and Roughness
4096 -> 512); `.gltf` and `.bin` files are byte-for-byte as shipped. All pieces share one 65-joint skeleton.
A dressed hero is about 25-30k triangles.
